# الأمان والخصوصية والتراخيص

## 1. الخصوصية
- لا تسجيل للشاشة ولا لقطات بدون فعل صريح من المستخدم. إن أضيف التسجيل لاحقاً، يظهر مؤشر واضح.
- لا Telemetry افتراضياً. أي إرسال تقارير أعطال يكون اختيارياً (opt-in) ويعرض محتواه قبل الإرسال.
- السجلات لا تحتوي محتوى الشاشة، ولا نصوص الحافظة، ولا معرّفات شخصية. الرقم التسلسلي للجهاز يُخفى (hash) في حزم التشخيص.
- الحافظة: لا مزامنة تلقائية في الإصدار الأول.

## 2. الهاتف
- الـ agent يُدفع إلى `/data/local/tmp`. هذا المسار قابل للكتابة من `shell` فقط وليس من كل التطبيقات، فلا يستطيع تطبيق خبيث استبداله قبل التشغيل (حسب وثائق scrcpy).
- يُتحقق من hash (SHA-256) للـ agent قبل التشغيل، ومن تطابق إصدار البروتوكول في handshake.
- الـ agent يستمع فقط عبر `localabstract` المحلي، ولا يفتح منفذ شبكة.
- **مدة حياة الـ agent = مدة الجلسة:** يُنهى عند إغلاق socket التحكم، ويحرر الأصابع.
- لا Root، ولا صلاحيات دائمة، ولا تطبيق مثبت (إلا Latency Probe للاختبار فقط).
- **شرح لتصحيح USB للمستخدم:** يمنح الكمبيوتر المتصل صلاحيات واسعة (تثبيت وقراءة وتحكم). ننصح بإيقافه بعد الاستخدام وبعدم قبول أجهزة غير موثوقة.

## 3. Windows
- **أقل صلاحيات:** التطبيق يعمل بدون Administrator.
- ملفات الإعدادات في `%APPDATA%`. لا توجد أسرار مخزنة في هذا المشروع. إن احتجنا لاحقاً لرموز، نستخدم DPAPI أو Credential Manager، وليس ملفات نصية.
- **التحديثات:** حزم موقعة، والتحقق من التوقيع وhash قبل التثبيت، والتنزيل عبر HTTPS فقط.
- **التحقق من مدخلات الشبكة:** كل رسائل الـ agent تُفحص (الأطوال والأنواع والحدود)، ولا ثقة في حجم حزمة بدون حد أقصى.

## 4. مكافحة الغش وشروط الألعاب
- لا تجاوز لأنظمة مكافحة الغش، ولا إخفاء للأداة، ولا تعديل لذاكرة أي لعبة أو ملفاتها.
- لا ماكرو آلي ولا تكرار تلقائي مفعّل افتراضياً. الميزات التي قد تخالف شروط بعض الألعاب، مثل الضغط المتكرر الآلي (turbo)، تُفصل خلف إعداد صريح مع تنبيه.
- تنبيه عند أول تشغيل: بعض الألعاب تمنع أدوات تعيين المفاتيح أو تضع مستخدميها في مطابقة خاصة.

## 5. التراخيص (تُراجع قبل كل إصدار)
| المكون | الترخيص | الالتزام |
|---|---|---|
| scrcpy (wrappers مشتقة أو server للـ PoC) | Apache-2.0 | حفظ إشعار الترخيص، وملف NOTICE، وتوضيح التعديلات |
| FFmpeg | LGPL-2.1+ (بدون `--enable-gpl` أو `nonfree`) | ربط ديناميكي، وإتاحة مصدر النسخة المستخدمة، والسماح باستبدال DLL |
| Qt 6 | LGPLv3 لمعظم الوحدات (بعضها GPL أو تجاري) | ربط ديناميكي، والتحقق من كل وحدة مستخدمة |
| `adb.exe` (Android platform-tools) | يخضع لاتفاقية ترخيص Android SDK | **قبل التوزيع:** مراجعة حق إعادة التوزيع. البديل: بناء adb من مصدر AOSP (Apache-2.0)، أو أن يثبّت المستخدم platform-tools بنفسه |
| nlohmann/json | MIT | إشعار |
| GoogleTest | BSD-3 | أدوات تطوير فقط |

لا يُستخدم أي كود أو شعار أو أصل أو بروتوكول خاص بمنتج WASD+ أو أي منتج تجاري آخر.
