# خطة الاختبار

## 1. مستويات الاختبار
| المستوى | الأداة | أمثلة |
|---|---|---|
| وحدات C++ | GoogleTest | CoordinateMapper (كل الاتجاهات وletterbox وDPI)، وPointerAllocator، ومنفذو التعيين (Tap وHold وJoystick وCamera)، وCoalescer، وتحليل رؤوس الفيديو، وترحيل الإعدادات |
| وحدات Agent | JUnit | تحليل البروتوكول، وPointersState، ورفض seq المكرر، وWatchdog |
| تكامل (PC + هاتف) | سكربتات + Latency Probe | جلسة كاملة، وتحقق من مواقع اللمسات عبر التطبيق |
| أداء | أدوات `poc/` و`tools/analysis` | ملفات CSV، ومقارنة بخط الأساس |
| تحمّل وطول | جلسة ساعتين | ذاكرة، وتسرب، وانقطاعات |
| يدوية | قائمة تحقق | ألعاب حقيقية |

## 2. الاختبارات الوظيفية (قائمة القبول)
| # | الحالة | النتيجة المتوقعة |
|---|---|---|
| F-01 | توصيل الهاتف | يظهر خلال أقل من ثانيتين، مع حالته (unauthorized أو device) |
| F-02 | فصل الهاتف أثناء اللعب | تحرير كل الأصابع، وفك قفل المؤشر، وحالة Disconnected، وبدون انهيار |
| F-03 | إعادة التوصيل | جلسة واحدة فقط، بنفس الإعدادات |
| F-04 | تدوير الشاشة | الصورة والإحداثيات صحيحة خلال إطار IDR واحد |
| F-05 | تغيير الدقة أو الوضع أثناء الجلسة | بدون إعادة تشغيل التطبيق |
| F-06 | Tap وHold وRelease | حدث DOWN واحد وحدث UP واحد |
| F-07 | سحب (Swipe) | مسار سلس، ولا UP مبكر |
| F-08 | 4 مفاتيح أو أكثر متزامنة مع الكاميرا | كل الأصابع مستقلة |
| F-09 | Alt+Tab أو فقدان التركيز أثناء الضغط | تحرير فوري لكل الأصابع وتحرير المؤشر |
| F-10 | مفتاح الطوارئ | يحرر المؤشر دائماً |
| F-11 | حفظ الإعدادات واستعادتها، وملف تالف، وإصدار قديم | تحقق، ثم ترحيل، ثم نسخة احتياطية، ورسالة واضحة |
| F-12 | إغلاق التطبيق أثناء الاتصال | تحرير الأصابع، وإيقاف agent، وإزالة tunnel |
| F-13 | رفض تفويض USB، أو جهاز Xiaomi بدون خيار الأمان | رسالة خطأ محددة مع خطوات الحل |
| F-14 | خادم adb بإصدار مختلف من أداة أخرى | كشف التعارض ورسالة واضحة، وبدون حلقة قتل متبادلة |

## 3. مصفوفة الأجهزة (تُملأ تدريجياً)

| هاتف رائد | Android 14 أو 15، Snapdragon 8 Gen أو Dimensity 9xxx | يُحدد |

| الشاشة | 60Hz و144Hz أو أعلى | يُحدد |

## 4. الأتمتة
- CI على Windows: بناء + اختبارات وحدات (C++ وJUnit) + تحليل ثابت (MSVC `/analyze` وclang-tidy) + فحص التراخيص.
- اختبارات الأجهزة تُشغَّل يدوياً أو على جهاز اختبار مخصص، لأن CI السحابي لا يملك هاتفاً عبر USB. النتائج تُرفع كملفات CSV.
- كل PR يمس `video/` أو `input/` يرفق نتيجة أداء مقارنة بخط الأساس (بوابة G-07).
